### How I work

- **Start with the people.** Requirements come straight from the finance, supply chain, clinical-operations and IT colleagues who work with customers.
- **Compose before coding.** Routine automation is built from ready steps in a low-code engine. Custom code is kept for what really needs it.
- **Keep people in charge.** AI drafts and automates, a person approves anything that matters.
